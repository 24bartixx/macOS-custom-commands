# Purpose

Are you tired of constantly typing 
```zhc
dart fix --apply
dart format .

```
Now you can perform all of it in one command
```zhc
flutter_prepare
```

Type in your Terminal
```zhc
curl -sSL https://raw.githubusercontent.com/24bartixx/macOS-custom-commands/main/flutter_prepare.py | python3
```
